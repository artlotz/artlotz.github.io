# 투기장 이미지 라이선스와 출처

`public/art/arena/`의 삽화와 배경은 아래 OpenGameArt 원문에서 받은 CC0 1.0 Universal 자료를 골라 WebP로 변환한 파생 파일입니다. 원본 파일을 핫링크하지 않습니다. 출처와 변환 내역은 [`manifest.json`](manifest.json)에 기록했으며, CC0 법률문 사본은 [`CC0-1.0.txt`](CC0-1.0.txt)에 보존했습니다. [Creative Commons 공식 CC0 1.0 법률문](https://creativecommons.org/publicdomain/zero/1.0/legalcode.txt)과 [deed](https://creativecommons.org/publicdomain/zero/1.0/)도 확인할 수 있습니다.

| 자료 | 제작자 | 원문 및 라이선스 |
|---|---|---|
| RPG Fantasy icons portraits - monsters, heroes, vampires (`free_sample.zip`) | Pan długa ryba | [OpenGameArt 원문](https://opengameart.org/content/rpg-fantasy-icons-portraits-monsters-heroes-vampires), CC0 1.0 |
| Fantasy RPG Icons 2 (`fantasy_rpg_icons_2.zip`) | Drummyfish | [OpenGameArt 원문](https://opengameart.org/content/fantasy-rpg-icons-2), CC0 1.0. 원문은 별도 표기가 필요하지 않지만 제작자 표기를 허용합니다. |
| PS1 Style RPG Pre-rendered Backgrounds (`ps1_pre_rendered_backgrounds.zip`) | CptDrunkBear | [OpenGameArt 원문](https://opengameart.org/content/ps1-style-rpg-pre-rendered-backgrounds), CC0 1.0 |

카드 이미지는 256×256 WebP, 배경은 원본 512×288 크기의 WebP로 변환했습니다. 아이콘도 256×256 WebP로 변환했습니다. 정확한 출력 경로, 원본 파일, 제작자와 변환 방식은 같은 폴더의 [`manifest.json`](manifest.json)에 기록했습니다. 전투장에서는 24개 카드 이미지 중 20개 인물·괴물 초상과 4개 마법 아이콘을 사용합니다.

이 폴더의 출처 기록은 재배포 시에도 함께 보존합니다. 다른 게임의 캐릭터·그림·로고는 포함하지 않았습니다.
